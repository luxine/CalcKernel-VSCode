# Security Policy

[简体中文](SECURITY.zh-CN.md)

## Supported versions

Security fixes are provided for the latest published extension release.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** feature to send a private report. Do not post exploit details, credentials, or other sensitive information in a public issue. If private vulnerability reporting is unavailable, contact the maintainers privately through the repository owner's GitHub profile.
